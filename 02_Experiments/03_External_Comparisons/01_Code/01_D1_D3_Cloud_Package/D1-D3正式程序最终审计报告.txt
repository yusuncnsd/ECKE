D1—D3正式外部对比程序最终审计报告

一、数据与Schema
1. 100条方法开发Gold与300条独立测试ID互斥。
2. 云端测试文件只有ann_id、record_id和原文，不包含专家盲标实体或关系。
3. 关系Schema直接使用正式xiaoke_schema_v5：7类实体、7种类型关系组合。
4. 100条条文级Gold转换为451个跨度实例；同形重复实体展开全部位置。
5. ann_014的猪肾荠汤、栝楼丸及其两条关系作为夹注打断例外，不进入连续跨度/关系端点监督；原始专家Gold不修改。

二、D1 CENTRELINE忠实重实现
已实现BERT-base-Chinese、BiLSTM、CLN二维网格、距离/区域嵌入、空洞率1/2/3卷积、双CTP头尾类型预测，以及带实体类型的主体/客体边界标记关系分类。NER使用256字符、64重叠滑窗，全文还原后去重；关系使用完整条文。RE训练使用Gold实体，测试使用D1预测实体。

三、D2 TCMERE忠实重实现
原TCMroberta权重和10类词典未公开，因此冻结为Chinese-RoBERTa-WWM-Ext替代编码器；每个训练折只用该折Gold表面形式构建词典，绝不使用消渴领域词表。实现五通道词典角色、BiLSTM、长度<=15跨度、初始实体评分剪枝、BCE多标签实体/关系损失和3层CompGCN。该方法必须报告为faithful reimplementation，而非官方原权重复现。

四、D3 BSTR-GPRel忠实重实现
已实现BERT、Jieba词性字符映射、附加Transformer、15%动态掩码、FGM对抗训练、可学习任务权重以及实体/关系头/关系尾三级GlobalPointer。解码要求实体跨度、关系头与关系尾一致，并通过正式Schema。

五、训练协议
固定五折80/20开发；每种方法比较两个预注册轮次候选并按五折平均联合F1冻结轮次；随后使用全部100条、3个固定随机种子训练并对300条无答案输入预测。D2阈值0.5来自官方代码默认；D3采用GlobalPointer标准logit阈值0；测试Gold不参与任何选择。

六、可靠性
每个方法保存模型、优化器、轮次检查点；运行绑定开发数据、测试输入、Schema、代码、随机种子和轮次指纹；推理逐条fsync落盘，重启只处理未完成ID。最终审计核对300条ID/顺序、实体原文位置、实体折叠、关系端点及Schema。

七、验证证据
1. D1、D2、D3原微型模型端到端回归均通过。
2. 正式入口使用临时微型BERT实际完成三方法训练、检查点、推理缓存和结果导出，CPU集成测试通过。
3. Python语法、Shell语法、资产哈希、五折数量、测试Gold隔离和正式机制静态审计通过。
4. 正式BERT权重和CUDA运行只能在AutoDL完成；云端首先执行GPU三方法最小验证，任一失败即停止后续正式训练。
